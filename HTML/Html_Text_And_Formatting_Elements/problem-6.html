Basic Notes and Code Examples for JavaScript, Java, and Python

JavaScript

JavaScript is a popular programming language mainly used to make websites interactive and dynamic. It can be used to create features such as buttons, forms, animations, and interactive web applications.

Important Concept: JavaScript is widely used for web development and interactive applications.

Example: Printing Hello World


let message = "Hello World";

console.log(message);

Key Point: The console.log() function is commonly used to display output in the browser console.

Java

Java is a widely used programming language known for its object-oriented programming approach. It is commonly used for developing desktop applications, enterprise software, and many other types of applications.

Important Concept: Java is based on important object-oriented programming principles.

Example: Printing Hello World


public class HelloWorld {

    public static void main(String[] args) {

        System.out.println("Hello World");

    }

}

Key Point: The main() method is the starting point for the execution of a basic Java program.

Python

Python is a simple and powerful programming language known for its easy-to-read and beginner-friendly syntax. It is used in web development, data science, artificial intelligence, machine learning, and automation.

Important Concept: Python is popular because of its simple, readable, and easy-to-understand syntax.

Example: Printing Hello World


message = "Hello World"

print(message)

Key Point: The print() function is used to display output on the screen.

Quick Revision

  • JavaScript: Used to make websites interactive and dynamic.
  • Java: Widely known for object-oriented programming.
  • Python: Known for its simple and readable syntax.
