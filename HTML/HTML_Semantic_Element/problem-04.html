Technical Definitions

RAM
Random Access Memory temporarily stores data and applications that the computer is actively using.
SSD
A Solid State Drive is a fast storage device used to store the operating system, applications and files.
Refresh Rate
Refresh rate describes how many times per second a display updates its image. A 144 Hz display refreshes up to 144 times per second.
